## 2. [역할 1] 소비자(Client) 화면 UI 구성 지침

소비자 화면은 목공 전문 지식이 없어도 직관적으로 치수를 조절하고, 장인의 질문에 답하며, 여러 공방의 제안을 시각적으로 비교할 수 있도록 구성한다.

### 2.1. 화면 구조 레이아웃 명세표

#### [모바일 소비자 화면: Bottom Sheet 구조]

| :--- | :--- | :--- |
| **상단 헤더 바** | 프로젝트 상태 배지 & BYOK 설정 | 진행 단계(`1_DRAFT_INIT` 등) 및 Gemini/OpenAI API 키 설정 모달 진입 |
| **중앙 뷰포트 (전체화면)** | 3D 실시간 뷰어 (Three.js) | 터치 회전, 핀치 줌, 팬 조작 및 60 FPS 기구학 도어 개폐 |
